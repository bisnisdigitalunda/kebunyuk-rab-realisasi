Backup, pindah perangkat & privasi

Penting untuk akses dari HP: aplikasi ini dapat berjalan di browser HP setelah file web dipublikasikan, tetapi versi ini menyimpan data secara lokal pada browser/perangkat yang dipakai. Data tidak otomatis sinkron ke laptop/HP lain.

Simpan cadangan data

Unduh file JSON untuk menyimpan daftar RAB, transaksi, dan simulasi PDH. Simpan cadangan di tempat aman.

Cara membuat aplikasi dapat dibuka lewat web

  1. Unduh file HTML aplikasi ini.
  2. Unggah ke repositori GitHub, misalnya repositori privat untuk pengelolaan sumber. Jika menggunakan GitHub Pages, perhatikan bahwa file web yang dipublikasikan dapat diakses publik.
  3. Aktifkan GitHub Pages pada pengaturan repositori dan buka URL yang diberikan dari browser HP.
  4. Untuk mengisi dari beberapa perangkat dengan data yang sama, perlu ditambahkan penyimpanan cloud/login (misalnya Firebase atau backend lain). Jangan menganggap localStorage sebagai sinkronisasi cloud.

Hindari menyimpan kata sandi, nomor rekening lengkap, atau data sensitif pada aplikasi ini. Tautan nota sebaiknya menggunakan izin akses yang sesuai.

Tombol “Hapus semua data lokal” akan menghapus transaksi dan perubahan yang tersimpan pada browser ini. Unduh backup terlebih dahulu.
